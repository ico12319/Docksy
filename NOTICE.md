# Artwork attribution

The Go gopher was designed by Renée French. The original design is licensed
under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).
See [The Go Gopher](https://go.dev/blog/gopher) for its origin and attribution requirements.

`assets/gopher.png` is an AI-generated adaptation of that design with a cyan
body, shaded cartoon rendering, and a wooden Docksy sign. The app icon is
derived from this image. These images retain the Go gopher attribution and
CC BY 4.0 notice; the MIT code license does not replace those requirements.
No endorsement by Renée French or the Go project is implied.

The cat and dog images were generated for this project with OpenAI's built-in
image generation tool. Their prompts, and the gopher generation/edit prompts,
are included in `assets/`. They are included under the project's MIT terms
to the extent copyright applies.

Keep this notice with redistributed source and app bundles. The build script
includes this notice and the code license in the app's Resources directory;
the About menu also credits the gopher design.
